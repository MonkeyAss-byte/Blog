## 一、C# 架构

### 1.1 SkinBody

皮肤主体管理类，负责将材质信息传递到 Shell 渲染管线。

#### 注册与初始化（逐 Body）

将 SkinMeshRenderer 信息注册到 SkinManager，按 Body 逐层添加。

#### SkinManager (Instance)

全局单例管理器，统一管理所有角色的毛发数据。

##### 几何形状

- **VertexBuffer (All)**：存储所有顶点的全局缓冲区
  - 注意：UV 只与顶点索引有关，与空间位置无关，故不需要额外存储 UV
- **RigidOffsetBuffer**：刚体偏移缓冲
- **RigidVelocityBuffer**：刚体速度缓冲

##### InstanceDataBuffer (All)

存储所有 Body 的 Instance 数据。

```
Foreach bodys {
    Foreach shells {...}  // 逐 Shell 循环
}
```

- `this.SetData` 完成数据绑定

##### 骨骼运动

- **preVertexBuffer (All)**：前一帧顶点缓冲
  - 从 `SkinMeshRenderer.getPreviousVertexBuffer()` 拷贝

### 1.2 SkinRendererFeature

#### PerDraw 逻辑（参数绑定）

- **环境光相关**：环境光照参数传递
- **M 矩阵 / M 矩阵的逆矩阵的转置矩阵**：法线变换矩阵
- **ShellCount**（当前 Body 的 Shell 层数）：用于 FurDepth 计算
- **ShellOffset**（当前 Body 相对于整体 ShellNum 的起始偏移）：确保正确采样 InstanceDataBuffer

## 三、毛发几何生成

### 3.1 单个毛发形成

- **极其高频密集的 Voronoi 图**：通过 Voronoi 噪声生成密集毛发结构
  > 💬 ShellDepth 在片元着色器中计算

### 3.2 Shell 相关概念

- **ShellDepth**：表示当前 Instance 毛发片段的深浅
- **非线性重映射 (ShellStep / ShellCount)**：对 Shell 层级进行非线性映射
- **Voronoi—SDF 图（有向）**：基于 Voronoi 的有向距离场

### 3.3 其他关键点

- **射线投射**：从平面上点计算顶点重心坐标 → UV → 切线空间流向值
- **毛发长短 Mask**：控制毛发长短的遮罩
- **使 Normal 方向随 FurDepth 反向**：深度越深，法线方向越反转
- **导致 Early_Z 失效的原因**：除非不写入深度，否则 Early-Z 优化会失效
- **效果与模型顶点密集程度正相关**：顶点越密，毛发效果越好
