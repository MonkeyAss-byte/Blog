# 漫威争锋 - 角色渲染

## 一、美术分析

![[Pasted image 20260909203729.png|352]]

- **整体美式风格**：具有PBR特征的美漫风格（镜面反射基于BRDF,漫反射进行风格化）。
- **色彩**：高饱和，多用冷暖对比（以及漫威漫画原有的对比色选色）。

### 人物画面元素

- **双描边**：
  ![[Pasted image 20260909203921.png]]
  - 描述：人物具有两层的外描边（1.近乎贴合人物轮廓的描边；2.具有鲜明转折且与人物不贴合）。

### 灯光与阴影表现（类三点照明法）

- **主光**：
  - **1. 自阴影**：
    ![[Pasted image 20260909204146.png|405]]
    - 描述：宽光且较硬，表现在漫反射被step为三层，分界线较为明朗
  - **2. 高光**：
    ![[Pasted image 20260909210304.png]]
    - 描述：在保证漫反射亮面表现得基础上，带有较硬且有明显色彩倾向的高光
- **边缘光**：
  ![[Pasted image 20260909204320.png]]
  - 描述：十分硬，且有明显转折（观察发现边缘光是附着在第二层外描边上的）
- **Kicker Light**：
  ![[Pasted image 20260909204726.png]]
  - 描述：与主光同侧。

## 二、技术实现

### 1. 基础光照模型

- **1. 直接光漫反射**：Half Lambert为基础，得到的值用来实现三阶阴影硬化
  
  ![[Pasted image 20260909205630.png]]

- **2. 直接光镜面反射**：基于微表面Cook-Torrance BRDF，用Specular Mask直接控制高光颜色，脱离漫反射独立受控
  
  ![[Pasted image 20260909210612.png|469]]

### 2. Skin Shading Model

- **1. 次表面散射**：在采样预计算次表面散射Lut基础上加上阶梯化阴影
  
  [[次表面散射]]
  
  ![[动画 (1).gif]]

### 3. Hair Shading Model

- **1. 高光**：Kajiya-Kay双层各向异性高光，各向异性贴图扰动切线偏移
- **2. 法线解耦**：漫反射使用模型几何法线，高光使用扰动法线

### 4. Kicker Light

- 基于虚拟光与人物法线的Power硬化，乘以主光阴影遮罩防漏光

### 5. 第一层描边

- 传统多Pass背面法线外扩（OutlinePass在透明前提取），齐次空间乘w消除距离影响，顶点色控制粗细

### 6. 边缘光与第二层描边

- **1. 由于边缘光不贴合人物模型，故通过DCC软件进行处理（原始资产文件为贴片法）**：
  - i. 体素化
  - ii. 法线扩张（保证不和原模型穿插）
  - iii. 顶点组信息传递
  - iv. 手动处理部分与原模型穿插的顶点
- **2. 深度偏移+菲涅尔遮罩**
- **3. 叠加Outline Pass并通过硬化进行Alpha Clip**
